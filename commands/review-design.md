Review the proposed change from first principles.

Arguments: `$ARGUMENTS`

Read [SKILL.md](../skills/challenge-the-design/SKILL.md) and follow it. Use the
supplied PR, diff, or design as the scope. When none is supplied, inspect the
workspace for the proposed change; ask for a target only when it cannot be
identified. Lead with the design assessment, support objections with evidence,
compare alternatives under the same guarantees, and then report implementation
findings. Keep unverified concerns as questions. Respect any required output schema.
Review does not authorize product edits or posting feedback externally.
